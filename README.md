# Ciao, sono Vincenzo! 👋

**Sviluppatore Full-Stack | Open Source & Self-Hosting Advocate**

Sono il creatore e lead maintainer di [KondoManager](https://www.kondomanager.com), un software gestionale open source per l'amministrazione condominiale. 

Mi concentro sulla creazione di architetture solide e scalabili, con particolare attenzione alla **contabilità in partita doppia**, motori di calcolo *penny-perfect*, ledger immutabili e rispetto assoluto della *data sovereignty* tramite soluzioni self-hosted.
